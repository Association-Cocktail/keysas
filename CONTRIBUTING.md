# How to contribute

Thank you to consider contributing to Keysas!

We are looking for contributions on the following topics:

- Support for other platforms
- Tests and bug fixes
- Support for certificate revocation
- Improvement of the admin panel
- New file analyzers for **keysas-analyze** (new file formats)
- Improvement of the **keysas-virustotal** caching and scoring policy
- Frontend improvements (progress display, check detail panel)

Contributions can be made via Pull Request for merging in the Develop branch.

They will then be pushed in new release on main, with minor number for bug fixes and major number for new features.
